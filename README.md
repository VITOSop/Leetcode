## 🧠 SQL (SQL 50)

I have completed the **LeetCode SQL 50 Study Plan**, covering key database concepts:

- Joins (INNER, LEFT, SELF)

- Window Functions (ROW_NUMBER, DENSE_RANK)

### 🔥 Key Learnings

- Writing SQL is about **thinking in data transformations**
- Handling **edge cases** is as important as writing queries
- Window functions are powerful for analytical problems
- Always distinguish between:
  - **latest vs maximum**
  - **count vs distinct count**
